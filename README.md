# Krish Real Estate 🏠

A modern, responsive real estate website built with **Next.js, TypeScript, and Tailwind CSS**.

The website is designed to showcase properties, provide property details, and make it easy for potential buyers or renters to contact the real estate business.

---

## ✨ Features

- 🏠 Property listings
- 📸 Property image galleries
- 🔎 Property details
- 📱 Fully responsive design
- 📞 Contact and enquiry options
- 🗺️ Location information
- 🎨 Modern real estate UI
- ⚡ Fast performance with Next.js
- 🚀 Ready for Vercel deployment
- 📦 No database or backend required for the current version

---

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Next.js App Router**
- **Vercel**
- **GitHub**
